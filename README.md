# Estudo de Raycast 2D

Atividade da faculdade de abr/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Teste de raycast em 2D. O jogador gira com as setas e lança um raycast pra frente que só detecta objetos de uma layer. Com K ele destrói o que acertou, e com espaço troca a layer entre Enemy e Water. Está tudo no `PlayerMove.cs`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2020.3.36f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
